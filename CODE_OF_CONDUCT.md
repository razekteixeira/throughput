# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep discussion about the work, and no harassment of any
kind. Report unacceptable behaviour privately through the repository's
[private report form](https://github.com/razekteixeira/throughput/security/advisories/new) (mark it as a
conduct report); reports are handled confidentially.

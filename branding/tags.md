# Modrinth tags

## Categories

Pick these three:

1. **technology**: the audience is tech and automation players running factories, and this is where they browse. Throughput measures and debugs automated production lines.
2. **management**: it is an admin and monitoring tool. It groups containers into named factories, adds alerts and a live ticker, and uses permission levels so it is safe on public servers.
3. **utility**: it is a general quality-of-life information tool that adds no blocks, items or gameplay.

Skipped:

- **storage**: it reads storage but does not add or extend any. Tagging it there would mislead people looking for storage mods.
- **optimization**: it does not make the game faster. People searching that tag expect performance mods.
- **game-mechanics**: it does not change how the game plays.

## Environment

- **Server:** required
- **Client:** optional (vanilla clients can join; the mod also runs in singleplayer through the integrated server)

## Loader and versions

- Loader: Fabric
- Game version: 26.3
- Dependency: Fabric API (required)
